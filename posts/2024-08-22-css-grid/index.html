CSS Grid 布局完全指南

从基础到进阶，全面掌握 CSS Grid 布局。两维布局的强大工具，让页面排版变得简单优雅。

#CSS#前端#布局

为什么需要 Grid

Flexbox 是一维布局，而 Grid 是二维布局。

当你需要同时控制行和列的时候，Grid 就是最好的选择。

基础概念

容器和项目

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: auto auto;
  gap: 20px;
}

网格线和网格轨道

  • 网格线（Grid Line）：分隔单元格的线
  • 网格轨道（Grid Track）：两条网格线之间的空间
  • 网格单元格（Grid Cell）：最小的单位

常用属性

容器属性

属性作用
grid-template-columns定义列
grid-template-rows定义行
gap间距
grid-template-areas命名区域
justify-items水平对齐
align-items垂直对齐

项目属性

属性作用
grid-column列起始/结束
grid-row行起始/结束
grid-area区域名称

实用技巧

1. 响应式网格

.container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 20px;
}

2. 经典圣杯布局

.container {
  display: grid;
  grid-template:
    "header header header" auto
    "nav main aside" 1fr
    "footer footer footer" auto
    / 200px 1fr 200px;
}

3. 居中神器

.center {
  display: grid;
  place-items: center;
}

Grid vs Flexbox

场景用哪个
一维布局（导航栏、列表）Flexbox
二维布局（卡片网格、页面整体）Grid
内容驱动（内容多少决定布局）Flexbox
布局驱动（先有布局再放内容）Grid

两者不是替代关系，而是配合使用。
