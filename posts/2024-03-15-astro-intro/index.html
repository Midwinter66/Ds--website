Astro 框架入门指南

Astro 是什么？为什么它被称为下一代静态站点生成器？它和 Next.js、Nuxt 有什么不同？一篇文章搞懂 Astro 的核心概念和群岛架构。

#Astro#前端#SSG#静态站点

什么是 Astro

Astro 是一个现代化的静态站点生成器（SSG），它的核心理念是"默认零 JavaScript"。

和 Next.js、Nuxt 等框架不同，Astro 在默认情况下不会向浏览器发送任何 JavaScript 代码。这意味着页面加载速度极快，用户体验非常好。

群岛架构（Islands Architecture）

Astro 最具特色的设计就是群岛架构：

  1. 页面大部分是静态 HTML（海洋）
  2. 需要交互的组件是一个个独立的"岛屿"
  3. 每个岛屿按需加载，互不影响
┌─────────────────────────────────┐
│  静态头部（无 JS）               │
├─────────────────────────────────┤
│  🏝  交互组件1（有 JS）          │
├─────────────────────────────────┤
│  静态内容（无 JS）               │
├─────────────────────────────────┤
│  🏝  交互组件2（有 JS）          │
└─────────────────────────────────┘

快速开始

# 创建新项目
npm create astro@latest

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

与其他工具的联动

Astro 不是一个封闭的生态，它可以和很多工具配合使用：

  • 内容管理：Contentful、Sanity、Strapi
  • 数据库：Supabase、Prisma
  • 部署：Vercel、Netlify、Cloudflare Pages
  • UI 框架：React、Vue、Svelte、Solid

总结

Astro 特别适合内容型网站，比如博客、文档站、作品集。它平衡了开发体验和性能，是个人网站的绝佳选择。
